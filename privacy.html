プライバシーポリシー

制定日：2026年9月27日（同日改定）

このページは、「市況解説アップローダー」（以下「本アプリ」）が扱う情報について説明するものです。 本アプリは、マーケット解説チャンネルの運営者が、自分のYouTubeチャンネルを運営するためだけに使う個人用の道具です。

1. YouTube API サービスの利用

本アプリは YouTube API サービス（YouTube Data API・YouTube Analytics API）を使っています。 本アプリを使うことは、YouTube 利用規約に同意することを意味します。 Google による情報の取り扱いについては、Google プライバシーポリシーをご覧ください。

2. 使う情報と目的

本アプリは、運営者本人の許可を得て、次の目的のためだけに情報を使います。

  • 自分のチャンネルに、動画・サムネイル・字幕を上げる、差し替える
  • 自分の動画に、固定コメント用のコメントを投稿する
  • 自分のチャンネルの再生回数などの数字を読み、動画づくりの改善に使う

ほかの方のアカウントの情報や、視聴者の個人を特定する情報は扱いません。

3. 情報の保存場所

  • 認証の情報（トークン）：運営者のパソコンの中のフォルダ（運営者本人の OneDrive で同期）
  • 動画のID・字幕の写し・再生回数などの数字：運営者のパソコンと、運営者本人の Google ドライブ

これらは運営者の動画づくりのためにだけ使い、必要がなくなったものは削除します。

4. 作業に使う道具

運営者は作業の補助に、AI アシスタント（Anthropic 社の Claude）と、自分あての通知（Discord）を使っています。 その作業の中で、自分のチャンネルの数字や結果をこれらの道具に読ませたり、自分あてに送ったりすることがあります。

5. 第三者への提供

本アプリが扱う情報を、第三者に売ったり、上記の目的以外で渡したりすることはありません。広告にも使いません。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる、Google API から受け取った情報の使い方と他のアプリへの受け渡しは、 Google API Services User Data Policy （Limited Use の要件を含む）に従います。

7. 許可の取り消しと削除

本アプリへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」 または Google のセキュリティ設定のページからいつでも取り消せます。 取り消したあとは、本アプリは新しい情報を読みません。保存済みの情報は運営者が削除します。

8. お問い合わせ

本アプリとこのポリシーについてのお問い合わせは、マーケット解説チャンネル（YouTube）からお願いします。
