プライバシーポリシー

制定日：2026年9月27日

このページは、「市況解説アップローダー」（以下「本アプリ」）が、Googleアカウントを通じて扱う情報について説明するものです。 本アプリは、マーケット解説チャンネルの運営者が、自分のYouTubeチャンネルを運営するためだけに使う個人用の道具です。

1. 使う情報

本アプリは、運営者本人の許可を得て、次の目的のためだけに YouTube Data API と YouTube Analytics API を使います。

  • 自分のチャンネルに、動画・サムネイル・字幕を上げる、差し替える
  • 自分の動画に、固定コメント用のコメントを投稿する
  • 自分のチャンネルの再生回数などの数字を読み、動画づくりの改善に使う

2. 情報の保存

認証の情報（トークン）は、運営者のパソコンの中にだけ保存し、外部に送ったり公開したりしません。 YouTubeから読んだ数字も、運営者のパソコンの中でだけ使います。

3. 第三者への提供

本アプリが扱う情報を、第三者に売ったり、渡したりすることはありません。広告にも使いません。

4. Google API サービスのユーザーデータに関するポリシー

本アプリによる、Google API から受け取った情報の使い方と他のアプリへの受け渡しは、 Google API Services User Data Policy （Limited Use の要件を含む）に従います。

5. 許可の取り消し

本アプリへの許可は、Googleアカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

6. お問い合わせ

本アプリとこのポリシーについてのお問い合わせは、マーケット解説チャンネル（YouTube）からお願いします。
